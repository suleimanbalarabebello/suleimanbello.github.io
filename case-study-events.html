01 — Overview

Making Events Accessible

LIVEINLDN addresses the fragmented landscape of event discovery for RnB, Afrobeats, and Hip Hop communities in London. Built as a full-stack solution with custom API, user authentication, and admin systems.

The Problem

Events for RnB, Afrobeats, and Hip Hop acts in London were scattered across multiple platforms, making discovery difficult for both event-goers and organizers. Existing solutions lacked focus on these specific communities and their needs.

The Solution

A focused events platform built from scratch with custom backend API, user authentication system, admin dashboard, and streamlined ticket access. Designed specifically for the London music scene with accessibility and user experience as core principles.

06 — Key Features

Platform Capabilities

User Authentication

Custom-built user registration and login system. Secure authentication allowing users to create accounts, manage profiles, and access personalized event recommendations.

Admin Dashboard

Comprehensive admin panel for event management. Create, edit, and delete events. Monitor user activity and manage platform content with full administrative control.

Ticket System

Streamlined ticket access and reservation system. Users can browse events and secure tickets. Payment processing was not implemented because this was an academic project.

Event Discovery

Intuitive search and filtering system focused on RnB, Afrobeats, and Hip Hop events. Browse by date, venue, artist, or genre with clean, accessible interface design.

Responsive Design

User-friendly interface designed for accessibility and ease of use. Clear typography, logical navigation, and thoughtful UX patterns throughout the platform.

08 — Impact

Key Learnings

Earned a First Class grade by delivering a complete full-stack application from concept through implementation. This project demonstrated end-to-end product development skills across design, frontend, and backend engineering.

Technical Growth

First experience building a complete full-stack application solo. Learned API design, database architecture, user authentication systems, and admin dashboard development alongside frontend implementation.

Working without frameworks forced deep understanding of core web technologies. This foundation makes learning React, Vue, or other frameworks significantly easier as the underlying principles are already solid.

Design Process

Developed systematic approach to UI/UX design: starting with user research and wireframes, iterating through multiple logo concepts, creating high-fidelity mockups, then implementing with code.

Accessibility and user experience guided every decision. Designing specifically for RnB, Afrobeats, and Hip Hop communities in London meant understanding the target audience deeply and building for their needs.

Project Management

Solo full-stack development required balancing design work, frontend coding, backend API development, and testing simultaneously. Learned to prioritize features, manage scope, and deliver a complete working product within academic deadlines.
